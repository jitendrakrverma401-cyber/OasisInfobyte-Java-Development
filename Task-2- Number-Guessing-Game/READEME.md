# Task 2 - Number Guessing Game

## Description

This project is a console-based Number Guessing Game developed in Java as part of my Java Development internship.

The computer randomly generates a number between 1 and 100, and the player has a maximum of 7 attempts to guess the correct number.

## Features

- Random number generation between 1 and 100
- Maximum 7 attempts per round
- High and low hints
- Multiple rounds
- Score tracking across rounds
- Final game summary
- Option to play again

## Technologies Used

- Java
- Java Scanner
- Java Random
- VS Code

## How to Run

1. Open `NumberGuessingGame.java` in a Java-supported IDE such as VS Code.
2. Run the `main()` method.
3. Enter your guesses in the terminal.
4. Follow the hints provided by the game.
5. Play multiple rounds and view the final score summary.
